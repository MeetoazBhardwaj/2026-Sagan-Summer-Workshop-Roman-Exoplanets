# Notes

This directory will contain concise technical notes that support the workshop notebooks without replacing the original teaching material.

Planned topics include:

- gravitational microlensing fundamentals
- point-source point-lens models
- binary-lens models and caustics
- finite-source effects
- chi-square minimization
- MCMC and parameter inference
- Roman exoplanet survey context
- Galactic Center and Galactic-population context
- SED fitting
- a glossary of recurring astronomy and modelling terms

Each note should connect directly to one or more notebook exercises and explain the scientific meaning of the computation, not just the Python syntax.

# Workshop Materials

This directory contains the **unchanged/default source materials** distributed for the **2026 Sagan Summer Workshop: Exoplanets with Roman Surveys: Microlensing and Transits**.

The purpose of preserving these files separately is to let learners attempt the exercises from the workshop templates before looking at participant-completed copies.

## Contents

```text

├── SSW2026_Google_Colab_Instructions.pdf
└── notebooks/

    │   ├── SSW2026_HandsOnI_Microlens_Setup.ipynb
    │   ├── SSW2026_HandsOnI_SingleLens.ipynb

```

## Where to start

1. Read [`SSW2026_Google_Colab_Instructions.pdf`](SSW2026_Google_Colab_Instructions.pdf).
2. For Hands-On Session I, run `SSW2026_HandsOnI_Microlens_Setup.ipynb` first.
3. Work through the remaining Session I notebooks in order.
4. For Session II, follow the data-access instructions in the workshop PDF and then work through the Galactic-context notebook and group projects.
5. Attempt the exercise cells yourself before opening the corresponding notebook under `../completed-notebooks/`.

## Preservation rule

Files in this directory are kept as workshop-provided source copies. Existing instructional text, starter code, authorship, citation, metadata, and attribution are not intentionally altered for participant solutions.

Participant answers, executed outputs, and later analysis belong in [`../completed-notebooks/`](../completed-notebooks/), not here.
